# Confirmed markings and datasheets

This page records markings that can be read from the repository photographs.
It does not infer hidden suffixes, manufacturers, values, or circuit functions.

## `MC705J1ACDWE`

The large 20-pin device is marked `MC705J1ACDWE`.
NXP hosts the [MC68HC705J1A family data sheet](https://www.nxp.com/docs/en/data-sheet/MC68HC705J1A.pdf), which covers this ordering-code family.
The current NXP-hosted copy is also stored locally as [`Datasheet-microcontroller_MC705J1ACDWE.pdf`](../Datasheet-microcontroller_MC705J1ACDWE.pdf).

## `CD4060BCM`

The upper 16-pin device is marked `CD4060BCM`.
The legacy Fairchild data sheet is now hosted by onsemi as [CD4040BC and CD4060BC](https://www.onsemi.com/download/data-sheet/pdf/cd4060bc-d.pdf).
Its ordering table lists `CD4060BCM` as a 16-lead SOIC device.
The current onsemi-hosted copy is also stored locally as [`cd4060bc.pdf`](../cd4060bc.pdf).

## Texas Instruments `HC368`

The lower 16-pin device carries the Texas Instruments logo and the marking `HC368`.
The complete ordering code is not visible.
Texas Instruments hosts the [SN54HC368 and SN74HC368 data sheet](https://www.ti.com/lit/ds/symlink/sn74hc368.pdf).
The current Texas Instruments-hosted copy is also stored locally as [`sn74hc368.pdf`](../sn74hc368.pdf).

## `24C02`

The lower eight-pin device includes the readable marking `24C02`.
The photographs do not establish the manufacturer or complete ordering code.
No exact data sheet is linked because several manufacturers produced parts with this family marking.

## `32.768`

The metal-can component is marked `32.768`.
The photographs do not establish its manufacturer, exact part number, load capacitance, tolerance, or series resistance.
No exact data sheet is linked.

Their exact part numbers, dimensions, electrical values, and functions are not established by the available evidence.
